YAGNA DHRUVA '26 — frontend demo

Files: index.html, styles.css, script.js, theme.css.
Stack: HTML, CSS, vanilla JavaScript, Tailwind CDN utilities. No frontend framework or animation library.

The supplied Day 3 schedule is reproduced in script.js. Event cards, fees, capacities, and registrations are demo content. Registrations persist only in the visitor's browser localStorage; they are not sent to a server and do not issue real tickets.
